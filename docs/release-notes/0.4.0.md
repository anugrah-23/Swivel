# Swivel 0.4.0 — first preview

Drag a file, tap **Alt**, drop it on the wheel. Everything runs on your PC.

## What's in it

- **The wheel**: tap Alt mid-drag; tap again for Convert → Tools → Actions. Wedges rank by use.
- **Images**: JPG, PNG, WebP, AVIF, HEIC, GIF, TIFF, BMP, ICO, SVG, PDF · compress, resize, smart crop,
  rotate, strip metadata, combine into one PDF.
- **Audio and video**: MP4, WebM, MOV, MKV, AVI, GIF, MP3, M4A, FLAC, WAV, Opus, OGG · compress, trim,
  mute, frames, extract audio.
- **Documents and PDF**: DOCX, Markdown, HTML, EPUB, TXT · Office files to PDF · merge, split,
  compress, pages to pictures.
- **Archives**: ZIP, 7Z, TAR, GZIP · extract ZIP, 7z, TAR, GZ, RAR.
- **Actions**: copy path, copy file, move to, copy to, share, float, terminal, reveal.
- **No drag needed**: Ctrl+Alt+W for the Explorer selection, Ctrl+Alt+V for the clipboard,
  and "Spin with Swivel" on the right-click menu.
- **Safe by design**: originals are never modified; every job can be undone.

## Before you install

- **Windows SmartScreen will warn you.** This preview isn't code-signed yet, so Windows shows
  "Windows protected your PC". Choose **More info → Run anyway**. Signing is on the way.
- Installs per user, no admin needed, about 330 MB on disk. Windows 10 (2004+) or 11, x64.
- On Windows 11, "Spin with Swivel" sits under **Show more options** until signed builds arrive.
- HEIC photos need Windows' free HEIF and HEVC extensions from the Microsoft Store.
- Document conversion downloads Pandoc (40 MB) the first time, after asking.

Swivel updates itself from these releases.

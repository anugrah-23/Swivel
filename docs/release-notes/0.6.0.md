# Swivel 0.6.0 — Organise PDF pages

Drop one or more PDFs on the wheel, tap to **Tools**, and pick **Pages · Organise**. Every page
opens as a card:

- **Drag** pages into a new order (drag several at once after selecting them).
- **Rotate** left or right (Shift+R / R), **delete** pages you don't need (Delete).
- **Add PDF…** pulls in pages from another PDF, so you can combine and reorder in one go.
- **Save as new PDF** writes `name edited.pdf` next to the original; **Save selected** keeps just
  the pages you picked. Ctrl+Z undoes, Ctrl+A selects all.

Your original PDFs are never changed, and the new file can be undone like any Swivel job.

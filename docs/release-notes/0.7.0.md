# Swivel 0.7.0 — Edit text and images in PDFs

Drop a PDF on the wheel, tap to **Tools**, and pick **Edit · Text & images**. The page opens with
every line of text and every picture outlined:

- **Double-click a line** to retype it right where it is. Enter keeps the change, Esc cancels.
  Swivel keeps the PDF's own font when it has every letter you typed; otherwise that line switches
  to the closest standard font (or Arial, for non-Latin text) and the editor tells you so.
- **Drag** text or pictures to move them. Arrow keys nudge (Shift for bigger steps).
- **Pull a picture's corners** to resize it; it keeps its shape.
- **Add text** (T) and click where it should go; **Add picture…** drops one onto the page;
  **Replace picture…** swaps the selected one, fitted into the same space; **Delete** removes it.
- Ctrl+Z / Ctrl+Y undo and redo, Ctrl + mouse wheel zooms, Page Up / Page Down change pages.
- **Save as new PDF** writes `name edited.pdf` next to the original.

The text is really changed, not covered with a white box, so it stays searchable and copyable.
Your original PDF is never touched, and the new file can be undone like any Swivel job.
